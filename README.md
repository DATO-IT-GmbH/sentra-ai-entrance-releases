# SentraAI Entrance - Releases

Official OTA update packages for SentraAI door access control systems.

## About

This repository hosts release packages only. Source code is maintained separately.

## How Updates Work

1. Licensed devices check this repo for new releases
2. Update packages are downloaded and verified (SHA256 checksum)
3. Automatic rollback protects against failed installations

## For Device Operators

Updates are managed through the device dashboard:
**Settings → Updates → Check for Updates**
